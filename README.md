Vue Calendar Project

A Planner and Daily Memo App with Weather Display integration; Built with Vue 3, and Pinia.

Switches between Day, Week, and Monthly views; Tracks ToDos, See Weather Updates, and Organize Life.

Planned Integration With Google Identity.

RoadMap:

 Project Setup - Vue + Pinia, GitHub, Basic Scaffold
 Month/Week/Day UI - Toggled Views, Dark/Light View-Toggle
 Pinia ToDo Store - Central ToDos, Sync Across Views, Custom Labels
 Weather API - Daily/Weekly Banner, Month View Icons
 Google Login Integration - Secure User Data
 Final Polish/Testing - Stress Test, Prettify, BugFix
 Ship to Netlify for Publishing
How To Run Locally:

Clone this Repo:
1 git clone https://github.com/poisonpsychicghost-hue/Vue-Calendar-Project.git
Install Dependencies:
1 npm install
Start Dev Server:
1 npm run dev

https://localhost:5173
